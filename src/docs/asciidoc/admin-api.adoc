=== 권한 체계

==== 역할별 권한
[cols="1,1,3"]
|===
|역할 |역할 ID |권한

|일반사용자
|1
|기본 서비스 이용

|매니저 (MANAGER)
|2
|• 일반 사용자 정지/해제 +
• 사용자 목록 조회 +
• 사용자 상세 정보 조회 +
• 정지 이력 조회 +
• 관리자 작업 로그 조회

|관리자 (ADMIN)
|3
|• 매니저의 모든 권한 +
• 사용자 역할 변경 +
• 모든 사용자 관리 (매니저 포함)
|===

==== 보안 제약사항
- 모든 관리자 API는 JWT 인증 필요
- 관리자는 자기 자신을 대상으로 작업할 수 없음
- 매니저는 자신보다 높은 권한의 사용자를 관리할 수 없음
- 모든 관리자 작업은 로그로 기록됨

===== 유틸리티 메서드
- **정지 유형 변환**: `getSuspensionTypeDescription(Integer)` 메서드를 통해 정지 유형 코드를 한국어 설명으로 변환
- **역할 변환**: UserRole enum을 통해 roleId를 역할 문자열로 변환
  - 일반 사용자(roleId=1)는 USER 반환
  - 매니저(roleId=2)는 MANAGER 반환
  - 관리자(roleId=3)는 ADMIN 반환
